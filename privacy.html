Privacy policy

gmail-sync is a personal tool used only by its owner, for their own Gmail account.

  • It downloads the owner's own email and Gmail labels through the Gmail API.
  • That data is stored only on the owner's private home server and in the owner's private backups.
  • Nothing is shared with, sold to or shown to anyone else. No analytics or advertising is used.
  • The tool only reads mail. It does not send, delete or change anything in the Gmail account.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Google API data is used in line with the Google API Services User Data Policy, including its Limited Use requirements.
